This repository contains Java programs written while learning and practicing Java programming. The programs range from beginner-friendly examples to problem-solving exercises and cover:

Java Basics
Input and Output using Scanner
Conditional Statements
Loops
Arrays
Strings
Functions/Methods
Object-Oriented Programming (OOP)
Exception Handling
Collections Framework
Data Structures and Algorithms
Coding Challenges

The purpose of this repository is to improve coding skills, understand Java concepts, and build a strong foundation for software development and technical interviews.
